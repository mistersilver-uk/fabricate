# Relics

Premium crafting-icon artwork (`relic-blood`, `relic-catalyst`, `relic-entropy`, `relic-formula`, `relic-stone`, `relic-verdant`), small painted webp tiles.
They appear only in the GM Manager's premium crafting-icons advert (`ManagerPremiumIconsAd`), drawn as art tiles on the art ladder.
Never show them, or any premium signal, in the player window.
