# Logos

`fabricate-logo.jpg` — the Fabricate mark: four elemental roundels (earth, fire, air, water) around a crossed axis, over the FABRICATE wordmark.
Single ink, parchment `#f1d1b5`-like on a dark ink-blue ground, 8000 × 4500.
Place it on `fab-bg-0`-like grounds only; never recolour, crop the roundels from the wordmark, or redraw it.
Where the mark is too large, set the name in Spectral 600 instead (the app title bar does: `row-name` in `fab-text`).
