{%- comment -%} Documentation image slot. A page names a View Lab case id and this renders the frame generated from it. The case id is the only name the page carries: the asset path is built here, so a page can never point at a file that the map and the generator do not agree about. Parameters: case required, the View Lab case id alt optional, overrides the alternative text the map records for that case caption optional, a visible caption beneath the frame Both alt and caption are escaped. Neither is a place for markup: alt is read aloud in place of the image, where a tag is noise rather than emphasis, and a caption that wanted a link or a code span would be describing something the surrounding prose should be saying instead. The image source is resolved through relative_url so it works from any depth of the site. The bare relative paths used by the older hand-curated frames only resolve because every page carrying one happens to sit at the site root, and would break on a page in a subdirectory. Styled inline rather than through a stylesheet on purpose. A new stylesheet file anywhere in this repository arms the screenshot evidence gate, which is a needless gate on a documentation-only change. {%- endcomment -%} {%- assign slot_case = include.case -%} {%- assign slot_entry = site.data.screenshots.screenshots | where: "case", slot_case | first -%} {%- assign slot_alt = include.alt | default: slot_entry.alt -%} {%- capture slot_source -%}/img/screenshots/lab/{{ slot_case }}.webp{%- endcapture -%}
