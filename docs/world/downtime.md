# Downtime Preview

GMs can choose **World > Downtime** in the Crafting System Manager to explore Fabricate's downtime preview.
The preview is always available beside **World > Parties**, even when no crafting system is selected.

{: .note }
> The Fabricate Core preview is read-only.
> It does not create or change downtime activities, campaign records, party roles, rewards, world time, actor data, or settings.

## Exploring the preview

Use the **Tracking**, **Activities**, **Factions**, and **Settings** tabs to explore the four parts of the preview.
Each tab describes a possible Fabricate Premium workflow and shows a compact example board.
The **Subscribe on Patreon & download Fabricate Premium** button opens Fabricate's Patreon page in a new browser tab.

The preview remains usable when the Manager window is narrow or its navigation rail is collapsed.

## Installed companion extensions

An installed companion module can replace the Core preview with its own downtime workspace.
When that happens, the companion owns the available actions and data.
Consult that companion's documentation for its setup and use.

While a companion workspace is active, the navigation rail stays expanded on this page so its sections stay reachable, and its collapse button is disabled with an explanation.
Your usual collapse preference is left untouched and returns as soon as you leave the page.
